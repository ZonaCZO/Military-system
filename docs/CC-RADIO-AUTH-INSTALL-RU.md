# Карта через радиосвязь Military-system

Это исправление заменяет отдельный проводной канал карты на существующий центральный сервер, его Network ID, ключ, LOGIN, токен и роли. Работают беспроводные и проводные модемы. Используется тот же старый шифр, что в других программах: это совместимость, а не современная криптографическая защита.

1. Останови программы CC и сохрани копии их файлов и data.
2. На центральном компьютере замени `/server.lua` файлом `central/server.lua` из архива. Добавь `/server/modules/front_live_map.lua` из `central/server/modules`. Остальные модули и база пользователей остаются на месте.
3. Поставь кафедру `front_map` рядом с этим центральным компьютером. Старую отдельную программу `front_map_host.lua` останови: она больше не нужна.
4. Если точки уже созданы на отдельном сервере карты, перенеси его `data/front_map` на центральный сервер, предварительно сохранив обе папки. Не перезаписывай две разные базы точек без ручного объединения. Группы задаются прежним `groups.json`: ID аккаунта -> ASCII-ID государства.
5. На клиенте замени `/pr/military_map.lua` файлом `client/pr/military_map.lua`. Его обычный `.net_config.txt` сохраняется: карта читает те же Network ID и ключ. Старый `front_map_connection.json` больше не используется.
6. Запусти центральный сервер, затем карту. Войди обычным аккаунтом Military-system. Сервер определяется через `central_core`; вручную ID задавать не нужно. Пароль не сохраняется клиентом.

Если файла сетевых настроек нет, программа спросит Network ID и Encryption Key, как другие приложения. Ключ не должен быть пустым или `none`: вход по радио без шифрования запрещён. Используй одинаковый непустой ключ на сервере и клиенте. Если старый конфиг использует `none`, перенастрой всю сеть, сохранив резервную копию настроек.

Чтение/редактирование карты защищено проверкой токена и ID компьютера на центральном сервере. Группы и права редактирования прежние: солдат читает, командир/генерал редактирует. Повторный вход тем же аккаунтом в другом приложении заменяет его старую сессию — так уже устроена авторизация Military-system. При ошибке Login required перезапусти карту и войди снова.

Ограничения радиомодема CC остаются: дальность, измерение и загрузка серверного компьютера. При потере связи карта показывает OFFLINE и оставляет последний просмотр в памяти.

На GitHub обычный установщик: вариант 1 обновляет клиента, вариант 2 — центральный сервер и модуль карты. Вариант 3 отдельного сервера устарел.

Проверен синтаксис всех четырёх Lua-файлов. Реальный вход, обмен по радио и совместные точки ещё нужно проверить в Minecraft. Скрипты фронта/KubeJS этим исправлением не заменяются.

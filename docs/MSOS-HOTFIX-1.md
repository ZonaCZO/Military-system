# MSOS Hotfix 1

Исправления: доставка драйвера кириллицы на штабные ПК и КПК; установка через временный файл и резервную копию; прошивка КПК без очистки диска; запуск без multishell; разбор файлов базы как данных; сохранение базы через временный файл; обязательный токен с привязкой к компьютеру для защищённых команд; исключение пароля из ответа LOGIN.

Перед обновлением скопируйте папки компьютеров CC. Для существующего штаба замените `system.lua` файлом `system/system.lua`, а `pr/pda.lua` — файлом `install/pda_patcher.lua`. Добавьте `system/cyrillic_driver.lua` в `pr/system/cyrillic_driver.lua`. Для центрального сервера замените `server.lua` файлом `server/resistance_core.lua` и обновите `server/modules/auth.lua` и `storage.lua`. Не удаляйте `data` и настройки сети.

Для КПК драйвер должен находиться в `/system/cyrillic_driver.lua`. Если установлен `startup/cyrillic.lua`, сохраните его вне startup: приложения и ядро уже запускают драйвер сами. После обновления сервера войдите заново; последний вход одного пользователя заменяет прежнюю сессию.

## Military Map

Программа `system/military_map.lua` устанавливается на штабный компьютер в `/pr/military_map.lua`. Интеграция и подробная инструкция находятся в `integrations/front-map`. Она требует Front Director и KubeJS + CC:Tweaked. Карта только читает данные через периферию кафедры; точки локальные. Это отдельный канал чтения, не авторизация MSOS.

## Проверка и ограничения

Все Lua-файлы прошли проверку синтаксиса Lua 5.2. Мост карты прошёл модельные проверки воды, контроля и пропуска незагруженных чанков. В Minecraft изменения ещё не проверены. Проверьте вход, планы, метки, сохранение после перезапуска и работу КПК на резервной копии мира.

Это первый пакет, не полный аудит. RC4 и прежнее хранение паролей оставлены для совместимости; телеметрия узлов и тревоги ещё требуют согласованной аутентификации. Нужны дополнительная проверка полей сетевых пакетов и испытания при сбоях связи/диска. Пакет не содержит личные данные мира или секреты.

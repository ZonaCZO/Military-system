# Общая карта по сети Military-system

Теперь все вошедшие пользователи одного Network ID из `.net_config.txt` видят общие точки. Никакое название/ID государства и `groups.json` больше не нужны. Сеть определяется центральным сервером, не полем запроса клиента. Права прежние: солдат смотрит, командир и генерал редактируют.

На центральном компьютере останови сервер, сделай копию файлов, замени `/server.lua` и `/server/modules/front_live_map.lua` из архива. Запусти сервер и карту заново. Клиентскую программу менять не нужно, если исправление радиосвязи уже установлено. Кафедра должна оставаться рядом с центральным компьютером.

Сетевые настройки, аккаунты и data не заменяются. Новые точки хранятся в прежнем points.json под ключом `network:<Network ID>`. Старые группы и точки не удаляются, но автоматически не объединяются: такое объединение могло бы раскрыть метки других прежних групп. Для переноса конкретных старых точек понадобится выбрать их отдельно. При смене Network ID получишь отдельный набор точек.

На GitHub обычный установщик, вариант 2, обновляет сервер и модуль. Инструкции ранней v9 про обязательный groups.json устарели.

Проверен синтаксис Lua. Требуется проверка входа и общих точек в игре.

# Military Map v1

## Установка

1. Полностью закрой Minecraft: периферия CC регистрируется при старте.
2. Это обновление для уже установленного Front Director v7.5. Скопируй содержимое папки `minecraft` в папку Minecraft экземпляра с заменой скриптов. Конфиг областей в архив не включён: твои координаты войны и базы сохраняются. Нужны CC:Tweaked и KubeJS + CC:Tweaked (у тебя показан 1.0.1-beta).
3. Запусти мир. Поставь кафедру (`minecraft:lectern`) вплотную к продвинутому компьютеру CC:Tweaked. Кафедра становится периферией `front_map`.
4. Узнай ID компьютера командой `id` внутри его терминала.
5. Скопируй `computer/pr/military_map.lua` в `saves/<мир>/computercraft/computer/<ID>/pr/military_map.lua`. При необходимости создай папку `pr`. Не заменяй существующие программы Military-system.
6. Запусти `pr/military_map.lua`. В лаунчере Military-system приложение обнаруживается при повторном запуске лаунчера.
7. Для монитора: подключи продвинутый монитор и запусти `pr/military_map.lua monitor`. Текст вводится на компьютере, точка выбирается касанием монитора.

## Управление

- Стрелки — перемещение карты; `+`/`-` — масштаб.
- Tab — следующая боевая область из конфигурации фронта.
- R — обновление; Q — выход.
- Клик по клетке — координаты, контроль, местность и число исследованных проб.
- A — добавить точку в выбранный сектор: B база, T цель, R маршрут, N заметка.
- D — удалить локальные точки выбранного сектора.

Фон: зелёный — свободно, красный — занято противником, оранжевый — фронт, голубой — пересечение безопасной зоны, серый — вне войны. Голубой не означает, что весь сектор безопасен: точные границы задаёт конфигурация.

Символы: `~` вода, `=` река, `^` горы, `*` лес, `.` суша, `?` неизвестно, G гарнизон, O очаг.

## Что важно знать

- Это условная секторная карта, не снимок блоков мира. До пяти поверхностных проб дают приблизительную долю воды, а не точный процент площади. Небольшая река может пройти между пробами.
- Сканируется один сектор в секунду, только уже загруженные чанки; новые чанки не создаются. Неисследованные места не выдаются за сушу.
- Обследуется до 4096 секторов; фронт и области показываются независимо от этого лимита.
- Снимок состояния обновляется каждые 20 секунд. После старта подожди до 20 секунд.
- Точки и последняя карта сохраняются локально: `front_points.json` и `front_snapshot.json`. Сетевое совместное редактирование пока не добавлено.
- Максимум 256 локальных точек. При клике на сектор название его точки видно снизу. На большом масштабе клик выбирает северо-западный сектор клетки; для точности приблизь карту.
- Интерфейс этой первой Lua-версии на английском ASCII: стандартный терминал CC не отображает UTF-8 кириллицу напрямую. GUI штаба сохраняет поддержку RU/UK/EN.
- Кафедра даёт только чтение общей карты. Любой подключённый компьютер может читать её: это не защищённый канал авторизации Military-system. Размещай устройство в защищённом штабе. Команды сброса, спавна и оплаты здесь недоступны.
- Существующие авторизация, шифрование, радар и база данных Military-system не изменены. Размер сектора берётся из Front Director, а не из старого значения 32 в Military-system.
- Это первая интеграционная версия; в реальной игре нужно проверить регистрацию кафедры, выдачу снимка и касания монитора. Не проверено запуском Minecraft.

## Что можно добавить далее

Совместные точки через действующую авторизацию Military-system; линии маршрутов; время устаревания разведданных; список атакованных гарнизонов; переключение слоёв контроля и местности; отметки городов после надёжного обнаружения; локализация под установленный кириллический шрифт.
